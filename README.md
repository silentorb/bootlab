# Bootlab

Will It Boot?

Yes, it boots!

Bootlab is a playground for experimenting with building and running applications on QEMU

The primary goals of Bootlab is to:

1. Establish baseline executables to see how QEMU loads and runs different types of binary files.
2. Be an environment from which most of the QEMU stack can be easily debugged.
3. Experiment with light-weight virtualization
